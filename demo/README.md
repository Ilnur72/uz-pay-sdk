# UZ Pay SDK Demo Application

This is a comprehensive demo application showcasing all features of UZ Pay SDK.

## Features

- 🏦 All 5 payment providers (Payme, Click, UzCard, Humo, Apelsin)
- 📱 Responsive design
- 🔄 Real-time payment status
- 📊 Payment analytics dashboard
- 🔒 Secure webhook handling
- 📖 Interactive API documentation

## Tech Stack

- **Frontend**: Next.js 14, TypeScript, Tailwind CSS
- **Backend**: NestJS, PostgreSQL, Redis
- **Payment**: UZ Pay SDK
- **Deployment**: Docker, Nginx

## Quick Start

```bash
# Clone and install
git clone https://github.com/Ilnur72/uz-pay-demo
cd uz-pay-demo
npm install

# Start development
npm run dev
```

Visit: http://localhost:3001
