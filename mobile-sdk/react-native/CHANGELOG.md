# 📦 Mobile SDK Changelog

## Version 1.0.0 (2024-12-19)

### ✨ Новые возможности
- **Полная поддержка TypeScript** - Все интерфейсы и типы полностью типизированы
- **UzPayReactNative класс** - Основной класс для работы с платежами
- **useUzPay Hook** - React Hook для удобной интеграции в React Native приложения
- **5 платежных провайдеров** - Payme, Click, UzCard, Humo, Apelsin
- **Автоматическая обработка таймаутов** - Конфигурируемые таймауты для запросов
- **Продвинутая обработка ошибок** - Детальные сообщения об ошибках
- **WebView интеграция** - Примеры интеграции с WebView для платежных форм

### 🛠️ Технические улучшения
- **Peer Dependencies** - React и React Native как peer dependencies
- **Tree Shaking** - Оптимизированная сборка для уменьшения размера
- **ES Modules** - Поддержка современных модульных стандартов
- **JSDoc комментарии** - Полная документация в коде
- **Jest тесты** - Готовая настройка для unit тестирования

### 📚 Документация и примеры
- **Подробный README** - Полное руководство по использованию
- **Примеры кода** - Практические примеры для всех случаев использования
- **WebView компонент** - Готовый компонент для обработки платежей
- **PaymentScreen** - Полнофункциональный экран для тестирования

### 🔧 Настройки сборки
- **TypeScript 5.1.3** - Современная версия TypeScript
- **Строгие типы** - Включены все строгие проверки TypeScript
- **ESLint** - Настроенные правила для качества кода
- **Prettier** - Автоматическое форматирование кода

### 📱 Поддерживаемые платформы
- **React Native** >= 0.60.0
- **React** >= 16.8.0 (для использования хуков)
- **iOS** 11.0+
- **Android** API 21+
- **Node.js** >= 14.0.0

### 🚀 Установка
```bash
npm install @uz-pay/react-native-sdk
# или
yarn add @uz-pay/react-native-sdk
```

### 🔗 Связанные пакеты
- **uz-pay-sdk** - Основной серверный SDK
- **@uz-pay/server** - Серверная часть
- **@uz-pay/types** - Общие типы TypeScript
