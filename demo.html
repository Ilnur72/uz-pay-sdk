🚀 Get Started

1. Install the package:

2. Use in your project:

import { PaymentsService } from 'uz-pay-sdk';

const payments = new PaymentsService();

const payment = await payments.create({
  provider: 'payme',
  amount: 50000,
  orderId: 'ORDER_123'
});
